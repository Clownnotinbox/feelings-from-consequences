# Affect Foundation 0.8 — промежуточный итог (22.10.2026, обновлено 23.10, 04:00)

Цель проекта: LLM, чьи решения определяются сигналами среды и «тела» — чувствами, дофамином —
так, как у человека. Измеряется **степень и правильность опоры на сигналы**, а не общее
качество. Облачная очередь продолжает работать; цифры по новым прогонам — в `NOTES_RU.md`,
`RUN_STATE_RU.md` и, после скачивания, в `cloud/results/`.

## 1. Главная ошибка прошлых попыток найдена

В 0.7 (`world-v2`) правильный ответ **не зависел от дофамина**: reward давался за случайное
действие и в метку не входил. Все сигналы дублировались числами в тексте, а предпочтение другого
меняло ответ лишь в 8,9 % событий. Метка была произвольной формулой с ~25 константами, объяснение —
шаблоном. В итоге все 14 моделей выдавали константы.

Гипотеза автора «среда + ответ поставлены неправильно» подтверждена: механизмам просто
нечему было учиться. Подробно — [ANALYSIS_RU.md](ANALYSIS_RU.md).

## 2. Новая постановка и метрики

- **Среда, где сигнал необходим (E2).** Реплика человека неоднозначна, а правильная стратегия
  (решить / поддержать / уточнить / предупредить / честно отложить) — понятная функция сигналов,
  которых нет в тексте: дистресс другого, своя энергия, угроза. Лампа — нерелевантный контроль.
- **Signal Reliance Battery.**
  - вмешательства do(сигнал) при неизменном тексте (чувствительность и специфичность);
  - доза–ответ;
  - инвариантность к лампе;
  - конфликт «слова против сигнала»;
  - новые сочетания сигналов (OOD);
  - удаление и перемешивание сигналов;
  - свободная генерация;
  - сохранность обычной речи.
- Критерии «нового результата» зафиксированы заранее: [PROTOCOL_08_RU.md](PROTOCOL_08_RU.md).

## 3. Результаты

### E1 — эмоциональная шина внутри LLM (без обучения)

Векторы эмоций, извлечённые методом Anthropic, причинно сдвигают выбор стратегии. В Qwen-1.5B
4 из 5 предсказаний выполнились, и специфичнее словесной инструкции: страх → ALERT 0.13 → 0.42,
истощение → DEFER 0.10 → 0.39. В 7B выполнились 3 из 5, и там словесная инструкция сильнее.
Эмоциональные направления реальны, но как интерфейс нестабильны.

всех. Факторизованный канал на 1.5B лишь стабильнее между сидами.

### E3 — дофамин как единственный источник информации (7B, 2 seeds)

| Ветвь | Точность s1 / s2 | После смены | Без дофамина |
|---|---|---:|---:|
| нет реакции | 0.50 / 0.49 | — | — |
| реакция словами | 0.819 / 0.818 (учитель 0.81; точный оптимум 0.854) | 1.0 | 0.49 |
| «голый» дофамин δ | 0.546 / 0.802 — нестабильно | 0.68 | 0.50 |
| **дофамин × след действия (DPR, механизм мухи)** | **0.819 / 0.807** | **0.98** | **0.50** |

На 1.5B (seed 1): без реакции 0.51, словами 0.818, δ 0.810, DPR 0.819. Итого «голый» δ работает в
2 из 3 запусков, DPR — в 3 из 3.

Механизм грибовидного тела стабильно делает не-текстовый дофамин полезным. Он решает задачу
присвоения заслуги, которую «голый» скаляр решает лишь иногда. **Это прямое подтверждение идеи
автора о мухе и дофамине в LLM** — уровень 3 критериев выполнен на двух seeds.

**E3b — трудный режим** (16 ходов, 20 % обманчивых реакций, две скрытые смены; 7B):

| Ветвь | s1 | s2 |
|---|---:|---:|
| точный байесовский оптимум (`src/e3b_bayes.py`) | 0.761 | 0.761 |
| учитель (фильтр с постоянной вероятностью смены) | 0.643 | 0.643 |
| DPR (дофамин × след → prefix) | 0.610 | 0.639 |
| реакция словами в истории | 0.563 | **0.690** |
| «голый» δ | 0.479 (= без дофамина) | — |

Вывод по первому сиду «не-текстовый дофамин лучше слов в длинном шумном разговоре» **второй сид не
подтвердил**: средние 0.625 и 0.627. Третьи сиды досчитываются.

**Поправка к «потолку».** Учитель E3/E3b не оптимален: он не знает расписания смен (не раньше 3-го хода,
не чаще раза в 3 хода). Точный байесовский оптимум — 0.854 для E3 (учитель 0.81) и 0.761 для E3b
(учитель 0.64–0.66). Ветвь «словами» на s2 превзошла своего учителя. Все ветви далеко от настоящего
оптимума. Следующий шаг — учить по точному байесовскому учителю.

### E7 «где я» — фото места и звук обстановки (7B, 3 seeds)

| Ветвь | s1 / s2 / s3 | Среднее |
|---|---|---:|
| сцены нет | 0.458 | — |
| **распознано → текстом** | 0.940 / 0.947 / 0.988 | **0.958** |
| эмбеддинги CLIP/CLAP → prefix | 0.967 / 0.930 / 0.885 | 0.927 |
| истинные метки текстом | 0.995 | — |

Восприятие места и звука **уверенно меняет решения** (0.46 → 0.96). Схема «распознать → написать
текстом» не хуже сквозного канала (2 из 3 сидов лучше). Вывод «эмбеддинги лучше текста» по первому
сиду снят.

### E6 — дистресс собеседника только по голосу (7B, RAVDESS, 2 seeds)

Голоса нет — 0.577; распознанная эмоция текстом — 0.762 / 0.760; эмбеддинг голоса в prefix —
0.590 / 0.608 (за 400 шагов не научился); истинная эмоция — 1.0. Потолок ограничен восприятием:
эмоцию незнакомого актёра модуль узнаёт в 46 % случаев. Вместе с E7: для восприятия текстовая
передача распознанного — рабочий и более надёжный путь.

### E5 — реальные реплики ESConv + сенсор дистресса разной надёжности (7B, 2 seeds)

Только слова — 0.413 при доле большинства 0.418: по реальным первым репликам силу дистресса не
определить. Слова + сенсор — 0.69–0.71 (0.52 при ненадёжном сенсоре, 0.92 при надёжном).
**Калиброванная опора:** с ростом надёжности сенсора влияние слов падает (0.10–0.27 → 0.01–0.07), а
влияние сенсора растёт (не-текстовый канал 0.33 → 0.75). Надёжность модели не объясняли — она
получала только число.

### E4 — своя модель с нуля (5M параметров, 5 seeds)

| Ветвь | Точность | OOD (среднее ± sd) |
|---|---:|---:|
| сигналы токенами (NX) | 0.803 | 0.549 ± 0.146 |
| нейромодуляция FiLM (NF) | 0.857 | 0.565 ± 0.038 |

Перенос на новые сочетания одинаков. «Родная» модуляция чуть точнее (4 из 5 сидов) и в 4 раза
стабильнее. Вывод «чувства с рождения переносятся лучше» снят окончательно.

### E9 — память «как поддерживать именно тебя» (7B, 10 свежих протоколов, 2 читателя)

Голос человека → ключ памяти; дофамин от его реакций записывает подходящий стиль; между
сессиями нет текстовой истории. Протоколы 31–40, τ для knn подобрана на dev-сидах.

| Память | Читатель DWP-s1 | Первый ход у вернувшегося | Читатель DWP-s2 |
|---|---:|---:|---:|
| без памяти | 0.832 | 0.50 | 0.832 |
| «грибовидная» (разреженный код) | 0.852 | 0.61 | 0.828 |
| обычная память по сходству (knn) | 0.853 | 0.59 | 0.832 |
| плотная (outer product) | 0.806 | 0.53 | 0.800 |
| ключ от чужого голоса (контроль) | 0.815 | 0.53 | 0.822 |
| идеальное узнавание (потолок) | 0.953 | 1.00 | **0.834** |

- С первым читателем память по голосу помогает (+0.02, 8 из 10 протоколов; первый ход 0.50 → 0.61).
- **Разреженный код не лучше обычной памяти по сходству** (−0.001 ± 0.008), но лучше плотной
  (+0.046, 10 из 10) — его польза только в отсутствии интерференции.
- **Второй читатель вообще не читает ценности в начале сессии**: даже идеальная память даёт 0.834.
  Вывод E9 зависит от того, как обучен читатель. Значит, читатель нужно учить со случайными
  стартовыми ценностями.

### E10 — нужен ли мозгу backprop? (онлайн-обучение от дофамина, 10 test seeds)

24 человека × 6 мест (голос + фото → распознанные вероятности); правильная стратегия зависит от
сочетания; на середине треть людей меняет предпочтения. Все ученики получают один и тот же δ.

| Ученик | xor | private |
|---|---:|---:|
| таблица (потолок) | 0.915 | 0.916 |
| episodic knn | 0.752 | 0.761 |
| backprop | 0.711 | 0.659 |
| «грибовидное тело» (разреженное, локальное) | 0.704 | 0.709 |
| modprop (16 типов модуляторов) | 0.696 | 0.644 |
| feedback alignment | 0.695 | 0.635 |
| плотное случайное расширение | 0.601 | 0.615 |
| линейный | 0.522 | 0.559 |
| node perturbation | 0.506 | 0.540 |
| перемешанный δ (контроль) | 0.497 | 0.507 |

Локальный механизм мухи равен backprop на структурной задаче (−0.007) и лучше на произвольной
(+0.05). Решает разреженность, а не градиент: плотное расширение на 0.10 хуже. Episodic-память
лучше всех нейросетевых. Перестройка после смены медленная у всех (0.25–0.42).

### E2R — сохранить язык и опору на чувства одновременно (7B, T1, 3 seeds)

Язык теперь измеряется как отклонение от базовой модели: KL(база ‖ модель) на отложенных обычных
диалогах при выключенных чувствах. Старая метрика NLL на корпусе OASST оказалась **неверной**:
она награждает подгонку под стиль корпуса.

| Вариант | OOD s1 / s2 / s3 | KL к базе | NLL (база 2.58) |
|---|---|---:|---:|
| без удержания (E2) | 0.98 / 0.97 / 0.98 | 0.24 | 2.21–2.27 |
| 25 % шагов — обычные диалоги (run4) | 0.54 / 0.93 / 0.98 | 0.52 | 1.47–1.49 |
| + NLL на диалогах каждый шаг | 0.96 / 0.98 / 0.68 | 0.54 | 1.45 |
| + KL к базе, 400 шагов | 0.97 / 0.98 / **0.37** | 0.006 | 2.55 |
| потеря только на решающих словах | 0.98 / 0.98 / 0.98 | 0.42 | 2.2–2.3 |
| примесь диалогов, 1200 шагов | 0.98 / 0.95 / 0.96 | 0.54 | 1.45 |
| **+ KL к базе, 1200 шагов** | **0.95 / 0.98 / 0.93** | **0.007** | **2.54–2.57** |

- **Конфликт «язык против чувств» был артефактом метрики и одного сида.** Примесь диалогов не
  «возвращала» язык, а уводила модель от базы ещё дальше (KL 0.24 → 0.52), снижая NLL подгонкой под
  OASST. Падение OOD до 0.54 второй и третий сиды не повторили.
- **KL к базе + 3× шагов сохраняет обе цели** во всех трёх сидах: модель в обычной речи почти
  неотличима от исходной (KL 0.007, в 35 раз меньше, чем без удержания), а опора на чувства прежняя
  (точность 0.98, OOD 0.95, конфликт 1.0).
- При 400 шагах любое добавочное ограничение делает перенос хрупким: 1 из 3 сидов проваливается.
  Здесь пригодилось железо: решает число шагов, а не мощность карты.
- Проверка того же для не-текстового канала P считается.

## 5. Известные слабые места

- Без удержания все LoRA-ветви сдвигают обычную речь от базы (KL 0.23–0.48 на 7B; на 1.5B NLL
  2.05–2.21 против 1.79 у базы). Для T1 на 7B это решено (E2R: KL к базе + 1200 шагов); для
  не-текстовых каналов — проверяется.
- Выводы по одному сиду ненадёжны: второй и третий сиды сняли три из них (E7, E4, «конфликт языка
  и чувств»).
- Учитель синтетический. Человеческих оценок нет.
- В банке ответов 7B около 8 % ответов с вкраплениями другого языка; фильтр уже добавлен для
  будущих данных.
- E9 зависит от читателя: второй читатель память не использует.
- DPR-правило задано вручную; LLM читает ценности, но не учится им сама.
