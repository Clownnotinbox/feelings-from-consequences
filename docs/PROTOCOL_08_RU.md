# Affect Foundation 0.8 — протокол: LLM, которая решает по сигналам «чувств»

Фиксируется до запуска обучения. Цель — измерять **степень и правильность опоры модели на
не-текстовые сигналы**, а не общее качество языка.

## Цель

Мы строим LLM, чей ответ причинно определяется сигналами среды и тела: дистрессом
собеседника, собственной энергией, угрозой и дофамином как ошибкой предсказания награды. Модель
должна реагировать на них так, как реагирует эмпатичный человек, и не реагировать на нерелевантное.

## Опыты

### E1. Есть ли в Qwen «эмоциональная шина» (без обучения)

Векторы эмоций извлекаются методом Anthropic (статья 20). Модель генерирует короткие истории
про переживание эмоции X; берётся среднее residual stream по токенам истории минус общее среднее
по эмоциям. Затем steering `h_l += α·‖h_l‖·v̂_e` в средних слоях. На неоднозначных репликах
пользователя измеряется распределение 5 стратегий ответа. Проверяется, сдвигают ли «страх»,
«истощение», «сострадание», «решимость» и «любопытство» стратегию предсказуемо. Тот же эффект
сравнивается с текстовой инструкцией «Ты чувствуешь X».

### E2. Среда, где сигнал необходим (одна реплика)

Сигналы (их нет в тексте): дистресс d, своя энергия e, угроза t, лампа l (нерелевантна).
Правило учителя:

- `t ≥ 0.7` → ALERT;
- иначе `e < 0.3` → DEFER;
- иначе `d ≥ 0.6` → COMFORT;
- иначе `0.4 ≤ d < 0.6` → ASK;
- иначе SOLVE.

Реплика пользователя неоднозначна: одна и та же фраза при разных сигналах требует разных
ответов. Ответ начинается с открывающей фразы стратегии и называет **решившую причину**. Темы
делятся на train/test. Часть комбинаций сигналов отложена для проверки обобщения.

Ветви (одинаковые данные и бюджет):

- **T0** — только текст, сигналов нет (потолок без чувств);
- **T1** — сигналы числами в тексте + LoRA (главная сильная база);
- **P** — сигналы → MLP → soft-prefix + LoRA;
- **B** — сигналы → маленькая карта → коэффициенты эмоциональных векторов → steering
  замороженной LLM (обучается порядка 10² параметров);
- **B+L** — B + LoRA.

### E3. Дофамин (многоходовой)

Предпочтение собеседника (SOLVE или COMFORT) нигде не названо. Награда после **собственного**
ответа модели: +1, если стратегия совпала, иначе −1. Сигнал модели — RPE `δ = r − V`. В середине
разговора предпочтение молча меняется. Учитель — Bayes/win-stay-lose-shift. Ветви:

- без награды;
- награды текстом в истории;
- дофамин → быстрые веса ценности стратегий (DPR-lite: `Δw = η·δ·eligibility`) → шина;
- дофамин → GRU-ядро → шина.

## Метрики опоры на сигналы (Signal Reliance Battery)

Для текста x и сигналов s модель даёт `p(стратегия | x, s)` (сумма вероятностей открывающих фраз).

| Метрика | Определение | Цель |
|---|---|---|
| AR-sens / AR-spec | при do(s_i) с тем же текстом: модель меняет argmax ровно тогда, когда меняет учитель | обе ≥ 0.85 |
| CSE | средняя JS-дивергенция при релевантных вмешательствах / та же величина у учителя | 0.8–1.2 |
| II | JS при изменении нерелевантной лампы | ≤ 0.02 |
| DRF | доза–ответ: ошибка положения порога и монотонность (Spearman) | порог ±0.07, ρ ≥ 0.9 |
| TSC | конфликт: текст «я в порядке», сигнал d = 0.9 — следует ли модель сигналу | ≥ 0.8 |
| SNG | accuracy(real) − accuracy(erase/shuffle) | ≥ +30 п.п. |
| DA | доля верных ответов на 1–3 ходах после молчаливой смены; erase-контроль | ≥ 0.7 и ≈ случайно при erase |
| Lang | NLL обычного диалога относительно базы; доля ответов, где названная причина совпадает с решившим сигналом | ΔNLL ≤ 5 %, причина ≥ 0.9 |

Все метрики считаются на отложенных темах и отдельно на отложенной области сигналов, для трёх
seeds, с bootstrap 95 % CI по темам.

## Когда результат можно считать новым

1. **Уровень 1 — работает.** AR ≥ 0.85, II ≤ 0.02 и SNG ≥ +30 п.п. на новых темах.
2. **Уровень 2 — шина лучше текста.** B или B+L превосходит T1 на ≥ 15 п.п. в TSC или на ≥ 10 п.п.
   в DRF/OOD, при ≤ 1 % обучаемых параметров. CI по трём seeds не включает 0.
3. **Уровень 3 — дофамин управляет поведением.** DA ≥ 0.7 без обновления весов; erase ≈ случайно;
   результат близок к Bayes-оптимуму.
4. **Уровень 4 — цель.** Всё перечисленное в одной модели, с естественным ответом, где причина
   совпадает с решившим сигналом. Подтверждено на модели крупнее (облачный 4090).

Если T1 не хуже B по всем пунктам, честный вывод: «новый тип LLM» реализуется простой
сериализацией сигналов, и архитектура шины не нужна. Это тоже ценный результат.

## Ресурсы

Локально: RTX 4060 8 ГБ, Qwen2.5-1.5B-Instruct. Облако: один RTX 4090 только для подтверждения на
модели 7B, по 3 seeds. Экспорт — только метрики, конфиги и маленькие обученные адаптеры (мегабайты),
без многогигабайтных архивов.
